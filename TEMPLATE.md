# Reflections in Light — Template

This branch is a cleaned template intended as a starter for new projects.

What it contains
- Source code and project configuration
- No built artifacts (the `build/` folders were removed)
- Basic instructions to get started

Quick start
1. Create a new repo using this branch as a starting point, or clone this repo and switch to `template/clean`.
2. Install dependencies:

```bash
npm install
```

3. Run locally:

```bash
npm start
```

4. Build for production:

```bash
npm run build
```

Notes for maintainers
- Built files are intentionally removed from this branch. If you need to regenerate them locally, run `npm run build`.
- Keep `TEMPLATE.md` up to date with any setup or environment changes.
